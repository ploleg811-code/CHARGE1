# CHARGE — премиальный детейлинг-центр (Санкт-Петербург)

Многостраничный сайт премиальной студии детейлинга: кинематографичный дизайн, анимированный
автомобильный диск, каталог марок и моделей, конфигуратор услуг, корзина и форма заявки.

Стек: **React 18 + TypeScript + Vite 5 + React Router 6** — без тяжёлых UI-библиотек.
Вся анимация — на CSS и небольшом количестве `requestAnimationFrame`.

---

## 1. Быстрый старт

### Вариант «в один клик» (Windows)

Дважды кликните **`start.bat`** в корне проекта — он проверит Node.js, при необходимости
установит зависимости, запустит dev-сервер и сам откроет сайт в браузере.

> ⚠️ **Файл `index.html` нельзя открывать двойным кликом.** Это SPA-приложение на Vite:
> при протоколе `file://` браузер блокирует загрузку module-скриптов, поэтому вместо сайта
> вы увидите серый экран. Если открыть файл напрямую, на экране появится эта же инструкция.
> Сайт нужно открывать **через локальный сервер** (см. ниже).

### Ручной запуск

```bash
npm install       # установка зависимостей
npm run dev       # режим разработки → http://localhost:5173
```

Продакшен-сборка и просмотр результата:

```bash
npm run build     # проверка типов + сборка в ./dist
npm run preview   # локальный просмотр сборки → http://localhost:4173
```

После `npm run build` **не открывайте `dist/index.html` напрямую** — запустите
`npm run preview` и откройте `http://localhost:4173/`.

Дополнительно:

```bash
npm run typecheck # только проверка TypeScript (tsc --noEmit)
npm run images   # перекачать фотографии с Wikimedia Commons (PowerShell)
```

Требуется Node.js 18+ (проверено на Node 24.19.0 / npm 11.17.0).

## 4. Что реально работает

- **Навигация** — React Router, 12 страниц, активное состояние пункта, мобильное меню.
- **Каталог марок и моделей** — 14 марок / 51 модель; данные в `src/data/cars.ts`,
  интерфейс строится на типизированных структурах (`CarBrand`, `CarModel`),
  новая марка добавляется одним объектом в массив.
- **Выбор автомобиля** — марка + модель; выбор синхронизирован с URL конфигуратора
  (`/configure?brand=bmw&model=bmw-3`) и с корзиной.
- **Выбор услуг** — 8 услуг, у каждой вариант выполнения и набор дополнительных опций
  с пересчётом цены; добавление одной и той же услуги обновляет её опции, а не создаёт дубль.
- **Корзина** — добавление, удаление, изменение дополнительных опций прямо в корзине,
  отображение марки и модели, расчёт суммы только по позициям с известной ценой,
  кнопки «Продолжить выбор» и «Оставить заявку».
- **Сохранение состояния** — корзина и выбранный автомобиль пишутся в `localStorage`
  и восстанавливаются после обновления страницы и перезахода между страницами.
- **Форма заявки** — валидация телефона (10 или 11 цифр, 7/8 в начале), понятные
  сообщения об ошибках, состояние отправки.
- **Анимированный диск** — SVG-диск в шапке, в меню, на первых экранах и в логотипе.
  Вращение задаётся глобальной CSS-переменной `--wheel-angle`, угол живёт в модульном
  состоянии, поэтому **не сбрасывается при переходе между страницами** и продолжается
  после перезагрузки (сохраняется в `sessionStorage`). При `prefers-reduced-motion:
  reduce` вращение отключается.
- **Галерея** — фильтры по типу работ, лайтбокс с плавным открытием, закрытием по
  клику и по Escape, навигацией стрелками.
- **Карта Яндекса** — при наличии ключа подключается официальный JS API; без ключа
  показывается аккуратная карточка адреса со ссылкой «Открыть в Яндекс Картах»
  (никаких пустых блоков и выдуманных точек на карте).
- **Адаптивность** — на 390 px проверено отсутствие горизонтального переполнения
  на всех страницах, мобильное меню, читаемые заголовки, удобные кнопки.
- **SEO** — уникальные `title` и `description` для каждой страницы (хук `useSeo`),
  корректная иерархия H1–H3, `alt` у всех изображений, favicon, Open Graph-метаданные.

## 5. Дизайн и интерактив

- **Тёмная палитра:** глубокий чёрный фон с плавно «переливающимся» бордовым свечением
  (анимированные размытые пятна, `src/styles/global.css` → `.atmo-blob`).
- **Типографика:** Unbounded (заголовки) + Manrope (текст), локальные woff2, полная кириллица.
- **Анимированный диск:** SVG-диск в шапке, в мобильном меню, на первых экранах и в
  логотипе. Вращение задаётся глобальной CSS-переменной `--wheel-angle`, угол живёт в
  модульном состоянии, поэтому **не сбрасывается при переходе между страницами** и
  продолжается после перезагрузки (сохраняется в `sessionStorage`).
  При `prefers-reduced-motion: reduce` вращение отключается.
- **Полоса марок с красной стрелкой:** под шапкой на всех страницах. При выборе марки
  маленькая красная стрелка (не колесо) плавно и медленно (1.5 с) перемещается к
  активному пункту. Стрелки ‹ › по краям полосы плавно прокручивают её — так
  открываются Tesla, Range Rover и McLaren на узких экранах.
- **Плитка «+»** — нарисована стилями, не эмодзи. Плавающая кнопка в правом нижнем
  углу открывает пошаговую заявку; такая же плитка стоит последней в списке моделей
  на странице марки и открывает вариант заявки, у которого отличается только шаг 1
  (ввод своей модели вместо выбора из каталога). В общем окне заявки плитка «+» стоит
  в конце сетки моделей.
- **Мягкий переход между страницами** — лёгкое проявление со сдвигом 10 px, без
  «дёрганья» и без перекрытия текста.
- **Тяжёлый кинематографичный скролл** — сглаживание через экспоненту
  (не зависит от частоты кадров, поэтому не дёргается и не лагает). Клавиатура,
  тач-скролл и ползунок не блокируются; при `prefers-reduced-motion` — обычный скролл.
- **Оптимизация прокрутки:** убраны `backdrop-filter` с карточек и блоков
  (остались только на шапке, полосе марок и оверлеях), уменьшены радиусы размытия,
  добавлены `will-change` там, где идёт трансформация.

## 6. Пошаговая заявка (окно записи)

Кнопка «Записаться» (в шапке, в мобильном меню, на плитке «+» и в корзине) открывает
модальное окно с размытым фоном и скруглёнными углами. На телефоне окно превращается
в нижний лист на всю ширину.

1. **Автомобиль** — поиск по всем моделям, фильтр по марке, сетка из всех 51 моделей
   с фотографиями. Плитка «+» в конце сетки → режим **«Своя модель»** (свободный ввод).
   На странице марки плитка «+» открывает сразу этот вариант (отличается только шаг 1).
2. **Услуги** — выбор одного или нескольких видов работ с ценами.
3. **Контакты** — имя, телефон (с валидацией), комментарий, **дата и время прибытия**.

Итоговая сумма и выбранный автомобиль переносятся в корзину и сохраняются.

## 7. Анимации и производительность

- Появление секций — `IntersectionObserver` + CSS-переходы (без scroll-jacking).
- Лёгкий параллакс и «дымка» фона реализованы на CSS-градиентах и `transform`.
- Стандартная прокрутка мышью, клавиатурой и пальцем **не блокируется** — скорость
  скролла нативная, ощущение «тяжести» создаётся визуально, а не задержками.
- Тяжёлые эффекты (параллакс, зерно, блюр) на мобильных экранах сокращены.
- `prefers-reduced-motion` отключает анимации появления, выключает вращение диска
  и убирает переходы.
- Вращение диска — один `requestAnimationFrame` на всё приложение, запись идёт в
  CSS-переменную, React-ререндеров не вызывает.

## 7. Что сейчас демонстрационное (обязательно заменить)

1. **Цены.** В `src/data/services.ts` указаны демонстрационные цены «от … ₽».
   Они везде помечены сноской `SITE.priceDisclaimer` и словом «демо» в карточках.
   Замените на реальные цены студии или оставьте вариант «Стоимость после консультации»
   (тогда сумма в корзине не считается — это поддержано в коде).
2. **Форма заявки работает в демо-режиме.** Backend не подключён: заявка сохраняется
   локально и **не отправляется** владельцу студии — об этом честно сообщает плашка
   под формой. Для отправки задайте `VITE_LEAD_ENDPOINT`; обработчик должен принять
   POST с JSON вида:
   ```json
   { "vehicle": "BMW 3 Series", "phone": "+7 999 123-45-67", "name": "...", "comment": "...",
     "services": [{ "title": "...", "options": ["..."], "extras": ["..."], "price": 120000 }],
     "subtotal": 120000, "hasUnknownPrice": false }
   ```
   Место для подключения — `src/pages/Cart.tsx`, функция `handleSubmit`.
3. **Контакты — плейсхолдеры** (`src/data/site.ts`): телефон `+7 (812) 000-00-00`,
   почта `hello@charge-detailing.ru`, адрес «Санкт-Петербург». Замените на официальные.
4. **Карта.** Координаты студии (`SITE.mapCoords`) намеренно `null` — случайная точка
   на карте не выставлялась. Укажите реальные координаты и ключ
   `VITE_YANDEX_MAPS_API_KEY` (см. `.env.example`).
5. **Логотип.** Используется временный текстовый логотип с типографикой (компонент
   `src/components/Logo.tsx`) и SVG-диск, стилизованный по референсу из брифа.
   Официальный файл логотипа не найден и не подменялся. Для замены достаточно
   подставить `<img>` в `Logo.tsx` и `favicon.svg`.
6. **Фотографии.** Снимки взяты из Wikimedia Commons (открытая лицензия) и используются
   как демонстрационные. Это **не работы студии CHARGE**. Полный список — в
   `scripts/assets-manifest.json`. Основные файлы к замене:
   - `public/images/studio/*` — 10 изображений (бокс, мойка, керамика, интерьер, диски);
   - `public/images/brands/<марка>/*.jpg` — 51 фотография моделей;
   - `public/images/brands/<марка>.jpg` — 14 обложек марок.
   Скачать и заменить можно скриптом `npm run images` (правит структуру и имена).
7. **Отзывы, рейтинги и счётчики** на сайте не выдумываются: счётчики в блоке «О студии»
   (`STATS` в `src/data/site.ts`) — демонстрационные значения, замените их фактическими.

## 9. Безопасность и аккуратность работы с файлами

- Проект создан в **новой** папке `Детейлинг центр` на рабочем столе; существующие
  файлы и проекты на рабочем столе не изменялись и не удалялись.
- Опасных команд удаления в проекте нет; скрипты загрузки изображений только
  перезаписывают файлы внутри `public/images` и проверяют результат (JPEG-сигнатура,
  минимальный размер).
- Никаких выдуманных API-ключей, отзывов, рейтингов и подтверждённых цен.
